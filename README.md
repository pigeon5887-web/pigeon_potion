# Pigeon Potion

A potion expansion mod for Minecraft Forge 1.20.1.

## Features

* New potion effects
* Extended brewing system
* Custom brewing recipes
* JEI integration
* Chinese localization

## Requirements

* Minecraft 1.20.1
* Forge 47.4.10+
* JEI (Optional)

## Installation

1. Install Minecraft Forge 1.20.1
2. Place the mod jar into the `mods` folder
3. Launch the game
